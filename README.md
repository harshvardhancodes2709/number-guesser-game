# Number Guessing Game

A simple Python number guessing game where the computer generates a random number within a user-defined range. The player tries to guess the number and receives hints indicating whether their guess is too high or too low. The game tracks the total number of guesses taken to find the correct answer.

## Features
- Random number generation
- Input validation
- Higher or lower hints
- Tracks the number of guesses

## Technologies Used
- Python
- Random module
